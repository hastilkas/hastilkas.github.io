# 🌅 Сутки света — Байкал

**Интерактивное эссе: один мартовский день на льду Байкала. Прокручиваете страницу, и проходят сутки: сумерки, восход, полдень, закат, синий час, ночь и северное сияние**

Портфолио-работа про визуал: сколько красоты можно выжать из браузера без единой картинки и видео

## ✨ Что внутри

| Глава | Время | Что происходит |
|---|---|---|
| Предрассветье | 06:00 | Месяц, звёзды гаснут, над льдом первая синева |
| Восход | 07:09 | Солнце встаёт из-за берега, лёд на минуту становится медным |
| Прозрачный лёд | 10:30 | Курсор работает как лупа: под льдом светятся трещины и пузыри метана. Клик — и лёд трескается со звуком |
| Полдень | 13:00 | Цифры о Байкале со счётчиками |
| Золотой час | 18:45 | Живая палитра: цвета интерфейса считываются прямо со сцены |
| Синий час | 19:20 | Пояс Венеры и тень Земли над горизонтом |
| Ночь | 22:30 | Млечный Путь, лунная дорожка; клики по небу зажигают звёзды и складываются в созвездие |
| Сияние | 01:00 | Северное сияние, которое дрожит от курсора |
| Кадр на память | 01:24 | Сохранение текущего кадра в PNG вместе с вашим созвездием |

## 🎨 Приёмы

- **Скролл = время.** Положение страницы переводится в час суток, высота и путь солнца считаются для 53° с. ш. в марте.
- **Одна сцена — один шейдер.** Небо, облака, горы, лёд, звёзды и сияние рисуются фрагментным шейдером (`assets/js/shader.js`) без three.js.
- **Палитра со сцены.** Несколько раз в секунду страница читает пиксели кадра (`gl.readPixels`), перекрашивает интерфейс и сама решает, каким быть тексту: светлым или тёмным.
- **Звук без файлов.** Ветер, ночной гул, «пение» трескающегося льда и звон звёзд синтезируются через Web Audio API.
- **Циферблат.** Солнце на 24-часовом круге можно тянуть мышью или стрелками: страница прокрутится к нужному часу.
- **Ссылка на минуту.** `…/#22:30` открывает страницу сразу в этом времени.
- **Адаптивное разрешение.** Если кадр не успевает за 60 fps, сцена рендерится в меньшем разрешении.
- **Доступность.** Уважается `prefers-reduced-motion`, циферблат — это `role="slider"` с управлением с клавиатуры.

## 🚀 Запуск

ES-модули не работают через `file://`, нужен любой статический сервер:

```bash
python -m http.server 8095
```

Потом открыть http://localhost:8095. Для публикации достаточно GitHub Pages или Vercel: сборки нет.

## 📁 Структура

```
index.html            разметка и тексты глав
assets/css/style.css  типографика, HUD, появление текста
assets/js/shader.js   GLSL: небо, лёд, сияние
assets/js/scene.js    WebGL-рендерер, чтение пикселей, снимок кадра
assets/js/main.js     скролл → время, курсор, клики, созвездие, циферблат
assets/js/sound.js    синтез звука
```

Шрифты: Literata и Golos Text (Google Fonts).
