# hastilkas.github.io

Сайт-портфолио: https://hastilkas.github.io

Чистые HTML, CSS и JavaScript. Без сборки, без npm, без сторонних библиотек: что лежит в репозитории, то и показывает GitHub Pages.

## Что где лежит

```
index.html              страница: тексты, «Обо мне», вопросы
assets/js/projects.js   список проектов (сюда добавлять новые)
assets/js/main.js       отрисовка карточек, видео, тема, фильтр
assets/js/theme.js      запоминает светлую/тёмную тему
assets/css/style.css    оформление
assets/media/           видео и картинки проектов
assets/fonts/           шрифт Onest (лежит локально, без Google Fonts)
assets/img/og.png       превью ссылки для Telegram/VK (1200×630)
404.html                страница «не найдено»
```

## Как поменять текст «Обо мне»

Откройте `index.html`, найдите `✏️ НАЧАЛО ТЕКСТА` и замените абзацы в квадратных скобках на свои. Каждый абзац в своём `<p>...</p>`, жирный текст в `<b>...</b>`.

Там же, через поиск по `✏️`, находятся шаги «Как проходит работа» и ответы на частые вопросы: проверьте, что они совпадают с тем, как вы работаете.

## Как добавить проект

1. Подготовьте видео (см. ниже) и положите `.mp4` и превью `.webp` в `assets/media/`.
2. Откройте `assets/js/projects.js`, скопируйте любой блок `{ ... }` и вставьте в конец списка. Поменяйте тексты. Между блоками нужна запятая.
3. `git add . && git commit -m "Новый проект" && git push`. Через минуту-две сайт обновится.

Цифры в шапке («3 готовых проекта», «114 автотестов») пересчитываются сами из поля `tests`. Фильтр по типам проектов появится сам, когда проектов станет больше трёх.

Проверить локально перед пушем:

```bash
python -m http.server 8090
```

и открыть http://localhost:8090.

## Как пережать GIF или запись экрана в лёгкое видео

GIF на 8–30 МБ превращается в MP4 на 0,3–0,7 МБ без видимой потери качества:

```bash
ffmpeg -i demo.gif -an -movflags +faststart -pix_fmt yuv420p -vf "fps=24,scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -preset slow -crf 26 assets/media/myproject.mp4
ffmpeg -ss 3 -i demo.gif -frames:v 1 -c:v libwebp -quality 78 assets/media/myproject.webp
```

Вторая команда берёт кадр на 3-й секунде как превью. Размер видео (ширину и высоту) впишите в `media` в `projects.js`, чтобы страница не прыгала при загрузке. Узнать размер:

```bash
ffprobe -v error -show_entries stream=width,height -of csv=p=0 assets/media/myproject.mp4
```

## Публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий с именем **ровно** `hastilkas.github.io`.
2. Залейте в него содержимое этой папки:
   ```bash
   git init -b main
   git add .
   git commit -m "Портфолио"
   git remote add origin https://github.com/hastilkas/hastilkas.github.io.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через 1–2 минуты сайт откроется по адресу https://hastilkas.github.io.

## Безопасность и скорость

- Политика безопасности (CSP) в `<meta>`: скрипты, стили и шрифты грузятся только с этого сайта, картинки ещё с `avatars.githubusercontent.com`. Если добавите сторонний скрипт (например, Яндекс Метрику), его домен нужно будет дописать в CSP в `index.html`.
- Данные проектов вставляются на страницу как текст, а не как HTML, поэтому случайный `<` или кавычка в описании ничего не сломают. Ссылки вида `javascript:` отбрасываются.
- Видео не грузятся, пока до них не докрутили, и ставятся на паузу, когда уходят с экрана или вкладка скрыта. При включённой в системе настройке «уменьшить движение» видео не запускаются сами.
- Шрифт лежит в репозитории и разбит на кириллицу и латиницу, браузер скачивает только нужное.
